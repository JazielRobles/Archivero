# Archivero
Archivero es un sistema de gestión documental basado en web, desarrollado con Flask y SQLite, que funciona como un repositorio centralizado para el almacenamiento, organización y visualización de archivos administrativos o técnicos. La aplicación implementa una arquitectura cliente-servidor donde los usuarios, tras autenticarse, acceden a un explorador jerárquico de carpetas que organiza documentos mediante una estructura anidada con permisos granulares por usuario. El sistema destaca por su capacidad de conversión automática de documentos ofimáticos (Word, Excel, PowerPoint, CSV) a formato PDF mediante integración con LibreOffice en modo headless, permitiendo la previsualización directa de archivos en el navegador sin necesidad de descarga. Incorpora un completo modelo de permisos que distingue entre usuarios normales y administradores, donde estos últimos pueden gestionar usuarios, asignar accesos de lectura/escritura a carpetas específicas, revisar documentos marcándolos como verificados, agregar comentarios y eliminar tanto archivos como directorios completos. El sistema persiste los metadatos en una base de datos SQLite ubicada en el directorio de datos del usuario (%LOCALAPPDATA%\CT_Scanner_System), mientras que los archivos físicos se almacenan con nombres UUID para evitar colisiones y garantizar seguridad. Una de sus características más notables es la capacidad de iniciar automáticamente con el sistema operativo Windows mediante configuración del registro, y su despliegue profesional utiliza el servidor Waitress para servir la aplicación en el puerto 80 (con fallback a 8080), lo que la convierte en una solución ideal para entornos de oficina o pequeños despachos que requieren un sistema interno de archivo y control documental con mínima infraestructura.
